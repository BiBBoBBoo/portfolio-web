# Rishav Kundu Portfolio

A lightweight, responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run locally

Open `index.html` directly, or start a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Assets

- Certification badge: `assets/images/claude-certification.png`
- Resume: `assets/resume/Rishav_Kundu_Resume.pdf`

To replace the resume, overwrite the PDF at `assets/resume/Rishav_Kundu_Resume.pdf` while keeping the same filename.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project.
2. Open **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the repository's `main` branch and `/ (root)` folder, then save.
5. Wait for deployment and open the URL GitHub provides.

The site can be used directly at a repository subpath because all asset paths are relative.
